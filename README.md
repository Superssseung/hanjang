# 한장 일력

국민달력 화면 구성을 참고해 만든 한국형 일력 웹앱. `index.html` 한 파일로 동작(브라우저에서 바로 열기).

## 화면 구성
- **일력**: 연·월 / 미니 월력(화면 중앙) / 주차·요일, 기념일·음력·손 없는 날, 큰 날짜, 연·월·일 간지와 띠
- **월력**: 날짜 아래 음력·공휴일·절기, 오늘 표시, 주차, 오른쪽 넘김 표시 점선, 하단 설정·현재 시각
- **반기**: 1–6월 / 7–12월 고정 6개월 보기

## 조작
- 일력: 위로 밀면 다음 날, 아래로 밀면 전날 / 상단 월 누르면 월력 / 음력 누르면 돋보기 / 큰 숫자 두 번 누르면 오늘
- 월력: 위아래로 밀어 달 넘김 / 제목 누르면 반기 / 날짜 누르면 해당 일력 / 길게 누르면 돋보기 / 하단 시각 누르면 오늘
- 반기: 위아래로 밀어 반기 넘김 / 달 누르면 해당 월력
- 톱니바퀴 메뉴: 오늘 일력, 연력, 위젯 미리보기, 음력 돋보기, 날짜 읽어주기, 큰 글씨·넘김 소리·음력 표시·한자 병기 설정
- 데스크톱: 마우스 휠, 방향키로도 넘김

## 데이터 기준
- 음력: 브라우저 내장 한국 음력(dangi) 달력 계산
- 절기: 태양 황경 계산(시각 수 분 오차 가능)
- 월건: 음력 달 기준(예: 2014-12-10 = 을해월)
- 주차: 일요일 시작, 1월 1일이 든 주가 1주차
- 공휴일: 「관공서의 공휴일에 관한 규정」 대체공휴일 규칙 + 2026년까지 확정된 선거일·임시공휴일
